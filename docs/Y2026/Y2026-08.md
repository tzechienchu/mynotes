### MIPI_CSI2_TX with I2C on Xilinx

[MIPI_CSI2_TX with I2C on Xilinx](https://github.com/VideoGPU/MIPI_CSI2_TX)

VHDL code for using LVDS lines of Xilinx FPGA for MIPI CSI-2 TX protocol. The goal is to support sending video or any other data using FPGA that don't have a dedicated D-PHY compatible outputs. (HS and LP outputs modes). The rate is 800Mbit/Sec per lane, two lanes total + DDR clock. The code was tested and works as expected on KC705 evaluation board.
